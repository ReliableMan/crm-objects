# Объекты и задачи

Мини-CRM для строительной компании: постановщик ставит задачи по объектам (стройкам), исполнители
берут их в работу и отправляют на проверку. Все права и правила смены статусов проверяет база данных.

**Демо:** _ссылка будет добавлена после деплоя на Vercel_
**Тестовые доступы** — в сопроводительном сообщении.

## Стек

- React 19 + TypeScript (strict), Vite, Mantine, TanStack Query, React Router 7
- Supabase: Postgres (RLS, права на колонки, триггеры, RPC), Auth (email + пароль, регистрация выключена)
- Хостинг фронтенда — Vercel

## Запуск локально

Нужны Node.js 20+ и проект Supabase (бесплатного тарифа достаточно).

```bash
npm i
cp .env.example .env          # заполнить URL, публичный и сервисный ключи, пароль демо-пользователей
npx supabase login
npx supabase link --project-ref <ref>
npx supabase db push          # применить миграции
npm run seed                  # демо-пользователи и данные
npm run dev
```

Настройки проекта Supabase:

- **Authentication → Sign In / Providers:** выключить *Allow new users to sign up*, провайдер Email оставить.
- **Data API не выключать** — через него работает приложение (защиту обеспечивают RLS и права, а не отключение API).
- Бесплатный проект **засыпает после 7 дней простоя** — перед показом откройте дашборд Supabase и «разбудите» его.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run seed` | Создаёт недостающих пользователей и профили; демо-данные — только если объектов ещё нет |
| `npm run seed:reset` | Очищает объекты, задачи и историю (инструмент администратора, сервисный ключ) и заполняет заново |
| `npm run test:security` | Тест безопасности (см. ниже) |
| `npm run gen:types` | Перегенерировать `src/lib/database.types.ts` из схемы БД |
| `npm run build` | Проверка типов (приложение и скрипты) и сборка |

## Проверка безопасности

```bash
npm run test:security
```

29 сценариев атак **только с публичным ключом** — как злоумышленник из браузера: от имени постороннего,
исполнителя и постановщика. Чтение чужих задач и объектов, прямое изменение статуса и полей,
запрещённые переходы, подделка и удаление истории, выдача себе роли, регистрация, сброс данных.
Тест не портит демо-данные; если подходящей задачи нет, сценарий помечается как пропущенный.

## Где что лежит

| Путь | Содержимое |
|---|---|
| `supabase/migrations/` | Схема, бизнес-правила (триггеры, RPC `change_task_status`), права и RLS, сброс демо-данных |
| `scripts/` | `seed.ts` — демо-данные, `security-test.ts` — тест безопасности (запускаются локально) |
| `src/lib/` | Клиент Supabase (только публичный ключ), типы БД, подписи статусов, перевод ошибок |
| `src/api/` | Запросы и мутации (TanStack Query) |
| `src/pages/`, `src/components/` | Экраны и компоненты |
| `docs/` | Пояснения для руководителя и список решений |

Сервисный ключ используется только локальным `scripts/seed.ts`; во фронтенд и в Vercel он не попадает.
